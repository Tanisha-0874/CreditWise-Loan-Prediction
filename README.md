# CreditWise-Loan-Prediction
Project Overview:
CreditWise is a Machine Learning-based Loan Approval Prediction project that aims to predict whether a loan application will be approved or rejected based on applicant-related information.
The project explores different supervised machine learning classification algorithms and compares their performance using various evaluation metrics.

Objectives:
-Perform data preprocessing and handle missing values.
-Conduct Exploratory Data Analysis (EDA) to understand patterns and relationships in the dataset.
-Apply categorical feature encoding techniques.
-Analyze feature correlations.
-Train multiple machine learning classification models.
-Evaluate and compare model performance.

Technologies Used:
-Python
-Pandas
-NumPy
-Matplotlib
-Seaborn
-Scikit-learn
-Jupyter Notebook

Machine Learning Algorithms:
The following classification algorithms are implemented:
-Logistic Regression
-K-Nearest Neighbors (KNN)
-Gaussian Naive Bayes

Project Workflow:
1.Data Loading
2.Data Preprocessing
3.Handling Missing Values
4.Exploratory Data Analysis
5.Outlier Detection
6.Feature Encoding
7.Correlation Analysis
8.Train-Test Split
9.Feature Scaling
10.Model Training and Evaluation
11.Evaluation Metrics

The models are evaluated using:
-Accuracy
-Precision
-Recall
-F1-score
-Confusion Matrix
